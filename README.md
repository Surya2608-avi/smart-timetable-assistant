# Smart Timetable Assistant

An AI-powered scheduling assistant that integrates with Google Calendar.

---

##  Features
- View upcoming events
- Create new events
- Conflict detection
- Free slot finder
- Google OAuth authentication

---

##  Tech Stack
- Python
- Streamlit
- Google Calendar API

---

## How to Run Locally

1. Clone the repository
2. Install dependencies:

```
pip install -r requirements.txt
```

3. Add your `credentials.json` file
4. Run:

```
streamlit run app.py
```
